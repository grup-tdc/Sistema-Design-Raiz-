# sistema.md — decisões estruturais já tomadas neste projeto

> Mantido pelo agente diretor-de-arte. É a memória estrutural do projeto: o que toda peça nova do mesmo formato
> deve **reutilizar**. O `DESIGN.md` diz quem a marca é; este arquivo diz como ela já foi diagramada.
> Acrescentar um formato novo: o agente pode (registrando em `decisoes.md`).
> Mudar algo já registrado: só com aprovação da pessoa.

## Formatos em uso

### <formato, ex.: Reels 1080×1920>
- Peça de referência (aprovada): `pecas/<pasta>/renders/<arquivo>.png`
- Grade: margens … · colunas … · gutter … · linha de base …
- Zona segura usada: `--zona …`
- Escala tipográfica (px): … (papel de cada nível: título …, apoio …, rótulo …)
- Posições fixas: logo/assinatura …; CTA …; numeração …
- Pode variar entre peças: …
- Não varia: …
- Comando de auditoria deste formato:
  `node <scripts>/auditar.mjs <peca> --tamanho … --base … --escala … --fontes "…" --paleta "…" --zona …`
